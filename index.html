The Gallery: Selected Projects

Five projects by Dibyajyoti Nayak, displayed as hand-drawn cards in the 3D gallery room.

GuardianSOS — Real-time Personal Safety Web Application (Dec 2025 – Apr 2026)

MERN stack, Geolocation API, WebSocket. Sends real-time SOS alerts with live location tracking to registered emergency contacts, with a community alert network. Live demo deployed on Render.

RedZone — Location-Based Emergency Alert System (Jul 2025 – Nov 2025)

MongoDB, Express.js, React, Node.js. Users report hazardous locations, reviewed through an admin approval workflow, with SMS and email notifications to all registered users.

Fit Fusion — Online Fitness Platform (Dec 2023 – Apr 2024)

HTML, CSS, JavaScript, Node.js, Express.js, MongoDB. Workout plans, class schedules, progress tracking and community modules, with a fully responsive UI.

AirCanvas — Virtual Writing Tool using Hand Gestures (Dec 2024 – Apr 2025)

Python, OpenCV, MediaPipe, NumPy. MediaPipe tracks hands in real time and OpenCV interprets the movements, so you can write in the air with no pen or stylus.

Object Detection Tool (Jul 2024 – Nov 2024)

Python, OpenCV, Flask. Identifies and locates objects in images, videos and live webcam feeds using OpenCV DNN with a pre-trained SSD MobileNet v3 model.
